# Entregador Demo (demonstração web)

Protótipo funcional de um app de entregador, em React Native + Expo (TypeScript), exportado para a web.
Nesta demonstração todos os dados são simulados; não há backend, pagamentos nem mapas.

**Demo ao vivo:** https://porzelt.github.io/entregador-demo-web/

**Código do app (com testes e documentação):** https://github.com/Porzelt/entregador-demo

**API em NestJS + PostgreSQL do mesmo produto:** https://github.com/Porzelt/entregador-api

Fluxo: ficar online, receber pedidos simulados, aceitar ou recusar, acompanhar os status da entrega
(a caminho da coleta, coletado, a caminho da entrega, entregue), concluir e ver o histórico com os ganhos do dia.

![Demonstração](demo.gif)

Este repositório contém somente o build web usado pelo GitHub Pages. O app também funciona com a API real (modo API), descrito no README do código.
